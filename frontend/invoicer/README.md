# Invoicer — Frontend

Vite + React UI for Invoicer. The live app talks to the Express backend via `/api`.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
```

Vite proxies `/api` to `http://localhost:8000`.

## Tech

React 19 · Vite · Tailwind v4 · TanStack Query · React Router 7 · Motion ·
Recharts · lucide-react · `@react-pdf/renderer`.
